# 文档矢量画布

一个支持 PDF 和 PPTX 的轻量矢量绘图工具。阅读论文或讲义时，可以直接在原文上圈画，选中关心的一段，交给 Agent 在画布上解释或重画。生成的图可以手动编辑，也能让 Agent 根据选区继续修改。产品也支持从空白画布开始独立绘图。

参赛方向为**原创赛道第 2 题「轻量级矢量绘图 / 示意图工具」**。下文是当前产品设计和参赛验收目标。赛事要求见 [比赛规则](competition_rules.md)。

## 使用场景

读技术资料时，“这个箭头为什么指向这里”和“把这两组数据画清楚”都依赖眼前的位置。用户可以直接圈选原文，Agent 依据页面、圈选区域和问题起稿。用户可以一边核对原文一边改图，最后把整份批注保存下来，或将图单独导出到笔记或汇报。

## 两种模式

| 模式 | 入口和用途 |
| --- | --- |
| **Personal Mode** | 从空白画布开始，手动画图、编辑对象、本地保存和打开。基础绘图可独立完成。 |
| **Agent Mode** | 导入整份 PDF 或 PPTX 并翻页，在原文上沿用同一套绘图工具批注。可圈选局部或指定页范围，让 Agent 梳理内容、生成示意图或修改选中的现有对象。 |

## 核心功能模块

| 模块 | 参赛版功能 |
| --- | --- |
| **基础矢量画布** | 绘制直线、矩形、椭圆和自由笔迹，插入文字，调整字体、字号、颜色及图形样式。支持选中、移动、缩放、旋转和复制粘贴。 |
| **文档导入与浏览** | 导入整份 PDF（论文、讲义等）或 PPTX，按原顺序翻页并缩放查看。原文页面作为锁定背景，用户和 Agent 创建的图形作为可编辑对象叠在页面上，也可以在独立画布区域作图。 |
| **圈选与上下文** | 支持用选区标出原文区域，也支持选中现有图形。用户发起请求时，Agent 获取当前页或指定页范围，以及相关页面图像、可提取的文本和所选对象。通过选区明确“这里”“这两个”和“只改这一处”。 |
| **Agent 绘图与改图** | Agent 利用画布提供的创建、更新等操作，组合形状、箭头和文字。可以在原页添加解释，也可以画一张独立的可编辑示意图。生成图中的来源引用能定位到相应原文页，便于核对。 |
| **本地保存与导出** | 保存可重开的画布项目，保留页面来源、页内位置与可编辑对象。支持撤销和重做，Agent 的一轮修改可以整体撤销。选中的独立示意图可导出为 SVG。 |

PPTX 以静态幻灯片呈现，导入时可转换为逐页 PDF。画布的编辑范围是新增的矢量对象，原文用于查看和定位。项目文件保留可继续编辑的数据，SVG 用于复用导出时的图形。

## 人与 Agent 如何在同一张图上协作

1. **定位原文。** 导入整份材料并跳到相关页，在原文上画圈，或选中已经画好的对象。
2. **发起请求。** 直接说“解释这两块的关系”“把这两页画成流程图”或“只改我选中的两个箭头”。当前页、选区和相关对象随请求一并交给 Agent。
3. **在画布上接收结果。** Agent 在原页标注，或在独立区域用可编辑矢量对象作图。用户可以根据来源页核对图里的关系。
4. **继续改稿。** 用户亲手修改文字、布局或样式，也可以重新选中对象，让 Agent 只修改指定部分。选区外的手写标注和图形保留，一轮修改可整体撤销。
5. **保存或复用。** 保存项目后可以继续读原文、改图；独立的示意图可导出到笔记或 PPT。

**产品差异点**在于把“你指的原文”“你在图上改了什么”和“Agent 接下来该改哪一处”连到同一个工作空间。用户可以用圈画和选中表达意图，Agent 的结果也能继续编辑和追溯出处。

## 参赛演示与验收

主案例采用 **FlashVID 论文复现汇报**。导入完整 PPTX，翻到帧数与 token 预算的实验页，圈出两处数据，请 Agent 画出两组量如何变化，解释为什么这组对照无法支持固定 token 预算下增加帧数的结论。用户改写一条说明，再让 Agent 把选中的两条箭头改成并排对照。保存重开后核对批注仍与原页对齐、图形仍可编辑，再导出独立 SVG。

- **Personal Mode** 从空白画布完成基础图形与文字编辑、对象变换、复制粘贴及本地保存重开。
- **Agent Mode** 用真实 PPTX 和 PDF 检查逐页导入与定位，演示一次从圈选原文到生成图，再到人工修改、Agent 局部修改和保存导出的流程。
