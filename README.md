# 文档矢量画布

在 PDF 或 PPTX 的原页上画图、批注，也可以从空白画布开始。原稿和新增图元分层：底稿锁定，自己加上的形状、文字和连线可以继续编辑。文档在浏览器本地处理，不需要上传。

**当前可用的是 Personal Mode。Agent Mode 尚未实现。** 项目面向原创赛道第 2 题「轻量级矢量绘图 / 示意图工具」，详见[比赛规则](competition_rules.md)。

## 已实现

| 能力 | 当前可用功能 |
| --- | --- |
| **空白画布** | 绘制基本图形、直线、折线、曲线、箭头和笔迹，插入文字及本地 PNG/JPG。支持对象选中、定位、变换、复制粘贴和撤销重做。 |
| **显式连接** | 开启端点吸附后，连线可以绑定图形、文字、图片外框或另一条线。移动目标时端点随动；视觉相交不会自动建立关系。 |
| **PDF/PPTX 多页画布** | 从「打开项目」导入文档，保留原页顺序和尺寸。左栏逐页显示缩略图和对象，右键页面行可隐藏或显示该页底稿。原稿内容不直接编辑。 |
| **项目保存与离线重开** | 保存为可编辑 JSON 项目，保留每页的底稿、图元和页外草稿。应用已加载后，可在断网时用项目文件重开，不需要原文件。 |
| **导出** | 选中图元可导出 SVG。文档项目可按原格式导出整份、当前页或指定页码；按原页边界裁切，不扩页、不加页。 |
| **Agent 前置能力（E8）** | 已验证本地程序能按页读取对象与显式连接、在授权范围内批量修改、整批拒绝越权操作，并一次撤销成功的批次。没有模型调用、聊天界面或对外服务。 |

**格式边界：** PDF 导出保留原 PDF 已有的文本层，新增编辑层作为透明图像叠加；扫描页不做 OCR。PPTX 原页在浏览器渲染为静态底图，不需要安装 PowerPoint；字体和图表可能与原稿略有差异。PPTX 导出时，符合条件的新增文字、基本形状和直线可在 PowerPoint 中单独编辑；复杂或跨页边的图元转为局部图片。两种格式都应同时保留 JSON 项目，方便以后继续编辑。

## 本地运行

需要 Node.js `22.12+`（22.x）、`24.x`（从 `24.0.0` 起）或 `26+`。

```bash
npm ci
npm run dev
```

打开 Vite 在终端显示的地址（通常是 `http://127.0.0.1:5173/`）。点「打开项目」选择 PDF、PPTX 或已保存的 JSON，也可以直接从空白画布开始。验证命令见 [Personal Mode 验收清单](doc/plans/personal-mode/validation.md)。
