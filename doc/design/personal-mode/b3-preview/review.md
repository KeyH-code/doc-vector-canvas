## v3 · 按钮与工具状态 · 2026-11-21

- **文件操作**：参考水彩示例的 [Primary Wash / Soft Outline / Ghost](https://www.stylekit.top/styles/watercolor-style/showcase) 和暗色画廊示例的 [Outline / Amber Hairline / Text Link](https://www.stylekit.top/styles/gallery-dark/showcase)。新建用无底加号，打开项目用细描边和文件夹图标，保存项目用胶囊轮廓；亮色保存有雾蓝到灰青的渐变，暗色保存用琥珀细线，不加发光或渐变。
- **主题与状态**：主题保留日月图标，当前项是一枚嵌在胶囊轨道内的小标签；四种演示状态改用下划线标记，不再铺实底。只有这两组可交互，支持悬停、键盘焦点和切换。
- **绘图工具**：当前工具只突出图标的圆环和小圆点，名称仍在原位；撤销与重做并入一组轻底控件。布局、文案、画布与四个演示场景不变，所有业务入口仍是静态示意。

## v2 · 水彩纸 / 暗室画廊 · 2026-11-21

- **亮色｜水彩纸**：参考 StyleKit 的[水彩画风](https://www.stylekit.top/zh/styles/watercolor-style)。暖白实色画布、雾蓝控件和选中反馈，杏粉与淡青两处静态晕染只在画布外，错误提示用浅珊瑚底与深红棕字。
- **暗色｜暗室画廊**：参考 StyleKit 的[暗色画廊](https://www.stylekit.top/zh/styles/gallery-dark)。炭灰工作区、稍亮的画布、细描边和暖琥珀选中反馈，不用渐变或发光；错误采用独立的暗红棕底与浅珊瑚字。
- **如何看**：用顶部「设计预览」条切换「亮色 / 暗色」和「空白画布 / 选中图形 / 编辑文字 / 打开失败」。默认是亮色、选中图形；换主题不重置状态。两套主题共用布局、字级、按钮文案与示例内容。新建、打开、保存、绘图等入口仅为示意，不操作文件或画布。
- **请审核**：亮色晕染是否抢视线、暗色画布边界是否容易辨认、两套主题的工具及错误提示是否清楚。
