## 待补手测：真实 Windows 中文输入法

1. 在项目目录运行 `npm.cmd run dev`，用 Chrome 打开 `http://127.0.0.1:5173/spike.html`。手测时不要同时启动端到端测试（两者使用同一端口）。
2. 双击中文文字进入编辑。切到日常使用的 Windows 中文输入法，键入 `zhongwen`，候选窗出现后按该输入法的候选确认键，并单独试一次候选期的回车和取消；记录具体输入法与结果。候选期间不能误改画布，候选处理完仍能继续编辑文字。
3. 继续输入一行汉字并点空白，核对只新增一次提交。保存、重新打开文件，核对最终文本与换行。若无法满足，优先验证有明确输入焦点的文本框适配方案，而不是换掉整个画布引擎。

## 对 B 批的建议

保留应用自有对象状态：Fabric 拖动只负责预览，结束后读场景坐标，提交一次；程序改图后按正式数据刷新。底图和画布共享同一个视口变换，选区导出在独立画布上重建所选对象。B 批应重新实现正式模型、历史和文件校验；不把这个小样的固定 ID、示例图元和 JSON 格式当作产品契约。真实输入法补测或风险接受决定经评审后，再开始 B 批。
