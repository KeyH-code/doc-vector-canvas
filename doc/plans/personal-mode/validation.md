## 需求验收用例

| 对应需求 | 操作 | 预期及证据 |
| --- | --- | --- |
| P-01、P-08 | 从空白开始，反向拖出矩形，再画椭圆、直线、箭头和两笔自由笔迹；操作完成后点选各对象。 | 形状位置和方向正确；两笔分开可编辑；普通工具回到选择、画笔保留；零长度图形不落盘。浏览器测试走实际按钮和指针事件。 |
| P-02 | Windows 中文输入法输入 `帧数增加 & 预算不变`，加第二行，用双击进入编辑并改字体、字号、颜色；在候选词窗口按回车。 | 候选词正常提交，未建新图形或误退出；中英文和换行可保留。Playwright 用例测文字保存，真实输入法另外手测。 |
| P-03、P-04 | 单选矩形执行拖动、缩放、旋转；框选或 Shift 加选后整体移动；复制粘贴后改副本填充和描边。 | 原件不因改副本而变化；多选导出的目标正确；只有适用的样式可改。将正向/反向拖动、旋转后移动和近线命中纳入用例。 |
| P-05 | 保存后用全新浏览器上下文打开项目；比较下载文件与重开的 ID、几何、文本、样式和层叠顺序，再编辑并重新保存。另试取消打开、坏 JSON、未知版本和重复 ID。 | 正常文件完整恢复；坏文件不替换当前内容或清空其历史；打开成功后历史隔离，未保存提示在正确时机切换。 |
| P-06 | 创建形状后拖动多个指针帧，修改样式再撤销两次、重做一次；撤销后做新编辑。另测试文字输入和画布的快捷键焦点。 | 每次撤销只反转一次正式编辑；拖动不卡成多步；缩放视口不会插入历史；新编辑清空重做；输入中按删除只影响文本。 |
| P-07 | 同时画 A、B、C，仅选 A、B；包含中文 `&`、粗描边、旋转图形和箭头。分别在 50% 和 200% 视口导出，在浏览器和目标 PowerPoint 打开。 | 两次导出内容与可视边界一致，不含 C、背景或手柄；无裁边、文字可见、XML 合法。浏览器自动检查范围与内容；PPT 插入手测记录应用版本和字体表现。 |
| P-09 | 无模型调用生产命令入口：范围为 A、B，改 A 文本和 B 位置；再逐次测试目标为 C、未知 ID、无效几何。模拟底图以 50%/100%/200% 显示，另以不同设备像素比测试。 | 合法批次一次提交、一次撤销，C 不变；非法批次不改内容、不写历史；尺寸、位置与底图对齐。以纯单测比对 ID、状态和历史；以浏览器验证实际渲染跟随和不回环。 |
| P-10 | 用目前仓库的干净副本按 README 执行安装、构建、启动，打开原创示例，并完成一次场景演示。 | 所需版本、命令、端口、样例和许可证可追溯；不需要额外服务和密钥。核对 README AI 声明与实际开发记录一致。 |
