# 第一阶段需求：Personal Mode

状态：2026-11-20 随计划审核通过，尚未实现。依据：[产品 README](../../../README.md)、[比赛规则](../../../competition_rules.md)、[Personal Mode 调研](../../research/personal-mode-research.md)。实施见[开发计划](2026-11-20-personal-mode.md)，通过条件见[验收清单](validation.md)。

## 目标

让参赛者和评委能从空白画布独立完成一张示意图，保存到本地，换一个浏览器会话打开仍能改图，并能把选中的图导出复用。后续 Agent 能通过已存在的画布操作修改指定对象；本阶段不接入模型。

| 编号 | 类型 | 需求 |
| --- | --- | --- |
| P-01 | 比赛基础 | 能绘制直线、矩形、椭圆和自由笔迹。画好的对象可以重新选中，不是粘在画布上的像素；自由画笔每笔是一个对象。 |
| P-02 | 比赛基础 | 能插入和修改文本，支持中文输入法、换行、字号、颜色及至少两种有可见区别的本地字体选项。文字编辑时，输入法和文本自己的快捷键不触发画布命令。 |
| P-03 | 比赛基础 + 项目 | 能单选、拖动、缩放和旋转对象；可框选或 Shift 追加选择，再整体移动或复制。复制粘贴至少在本应用内有效，副本可独立编辑。首版不要求多选整体缩放和旋转。 |
| P-04 | 比赛基础 | 可调整适用对象的颜色与样式，包括描边颜色、线宽、实线/虚线；矩形和椭圆支持填充。选中不同对象时仅显示适用的属性。 |
| P-05 | 比赛基础 | 项目可显式下载为本地文件，也可从文件打开；对象 ID、位置、形状、文字、样式与层叠顺序完整保留。新建或打开前保护未保存改动；文件损坏、格式不支持、用户取消时保留当前画布。打开项目不继承上一张画布的撤销记录。 |
| P-06 | 项目进阶 | 创建、拖动、缩放、旋转、改文本/样式、粘贴、删除都可撤销和重做。一次手势、一次属性提交或一批修改只算一步；点击选择、预览、平移和缩放画布不算编辑。撤销后发生新编辑会清除重做分支。 |
| P-07 | 项目进阶 | 导出当前选中对象为 SVG；无选区时禁用该操作。导出裁切到所选对象（含描边、旋转及箭头末端），剔除底图、未选对象和操作手柄，不受当前画布缩放影响。项目 JSON 是继续编辑的入口，SVG 是复用的入口。 |
| P-08 | 项目交互 | 提供清楚的新建、打开、保存、绘图及撤销重做入口、未保存提示；单选可见缩放和旋转手柄。普通图形画完默认回到选择工具，画笔可连续画。支持简单箭头（不自动绑定形状）、删除、抓手/缩放。 |
| P-09 | Agent 扩展前置 | 手工操作和程序操作共用对象模型和提交规则。位置以画布坐标保存，不受浏览器缩放、高 DPI 或画布平移影响；背景与编辑层分离。程序可读取目标对象 ID，并在给定范围内执行建图、改图、复制或删除。合法批次可整体撤销；遇未知 ID、越界或无效值时整批不生效。 |
| P-10 | 交付 | Personal Mode 在目标 Windows 桌面浏览器可复现启动，不依赖账号、业务后端或 Agent 密钥；README 含真实的运行、使用、测试步骤，另列实际资源许可与 AI 使用、人机分工；提供一份可重开的原创示例。 |

## 明确不做

- PDF/PPTX 导入、原文圈选、上下文披露、模型调用、模型协议、Agent 实时改图均属于下一阶段。P-09 仅要求一个可在无模型条件下验证的内部入口，不要求对外发布接口。
- 不做云同步、协作、模板库、图层面板、吸附对齐、自动连线、PNG 导出、富文本、跨应用粘贴矢量或移动端适配。
- 只承诺通过浏览器下载和文件选择完成保存、打开；不承诺覆盖原路径或以浏览器缓存作为存档。中文字体允许系统回退，不承诺跨操作系统像素级一致；实际演示环境的字体与 PPT 兼容性按验收记录说明。

## B 批开发约束

先验证不依赖页面的画布核心，Personal Mode 不新增独立后端服务。核心通过后先提交页面预览；只有参赛者对整体风格明确批准，才开发正式页面。纯视觉预览不算产品功能，见 [B 批实施计划](2026-11-20-personal-mode-b.md)。
