# Personal Mode 画布扩展 · 验收清单

**状态：2026-11-22 计划已批准；本清单是验收标准，不是测试结果。** 关联：[需求](requirements.md) · [实施计划](../2026-11-22-personal-mode-expansion.md) · [原回归清单](../validation.md)。

## 验收矩阵

| 编号 / 对应需求 | 操作或输入 | 可验收结果和证据 |
| --- | --- | --- |
| **X-01 / E-01、E-12** | 从 C3 真正下载一个 v1 项目；在新版打开、保存 v2，再用新的浏览器会话打开。另试未知版本、坏 JSON、缺失图元/资源引用。 | 比对对象 ID、层叠顺序、文字、样式和几何。坏文件不替换项目、不丢失撤销/重做。单测检查错误分支；浏览器检查实际下载、打开。 |
| **X-02 / E-02、E-03** | 平移到原纸面的右上、左下各画一个对象；以不同倍率打开/缩放，拖分隔栏、收起侧栏、进入/退出全屏，并跑 `1×`、`2×` 设备像素比。 | 可在正负世界坐标创建、移动、点选；缩放锚点和容器调整前的世界中心稳定。比对项目对象坐标，视图动作无历史、无未保存提示。验证输入时按空格不会误启动抓手。坐标单测 + Chrome 浏览器 + Windows Edge 手测。 |
| **X-03 / E-04、E-05** | 建立三矩形、一箭头、一直线；在左栏展开矩形、整组选中、用 `Shift` 增减一项，再在画布上框选；从侧栏定位视口外的对象。 | 展开本身不改选区；对象 ID、计数、高亮双向一致，不误选其他类型；可见坐标、形状适用尺寸和颜色。`1280×800`、`1440×900`、亮暗主题下长列表可独立滚动。 |
| **X-04 / E-06** | 从「其他图形」拖出正方形、菱形、五角星，反向拖绘，编辑样式、变换、撤销、保存重开，并选中导出。 | 正方形宽高一致；其他两形保持正确轮廓，重开后仍可编辑。零面积不入历史；厚描边和星尖不被裁掉。单测核对几何，浏览器核对真实操作和 SVG。 |
| **X-05 / E-07、E-08** | 不开吸附，在矩形内画线、让线穿过或贴近图形。打开吸附，将箭头两端分别接到矩形任意边点、椭圆任意弧点；之后对菱形和星形凹边重复。移动、缩放、旋转宿主，关闭吸附，再移动原宿主。 | 自由线不产生关系；只有端点确认后，侧栏与核心才出现同样的连接；连接随变换保持原局部位置，关闭开关不解除既有绑定。用不同倍率验证近边候选，放大时检查凹边没有吸到包围框。 |
| **X-06 / E-08、E-09、E-10、E-13** | 拖离端点、改接另一对象；删除一端宿主后撤销；同时复制节点与线、只复制线、只复制节点；尝试受限删除但不授权相邻连线。 | 取消/改接只改该端；删除保留线及原端坐标，撤销恢复。副本 ID 与连接重映射正确，无暗中新增关系；未授权的关联记录若需改写则整批拒绝。重叠导致端点暂同点时保留逻辑连接，不画伪箭头。 |
| **X-07 / E-10、E-11** | 分别选中「有连接的箭头、不选宿主」和「部分图形 + 箭头 + 图片 + 表格」。在不同倍率、主题和观看位置下载 SVG，在浏览器和目标 Windows PowerPoint 插入。 | 仅导出选中对象，线解析到正确端点；画布外观、背景、手柄和未选宿主不进入输出。长中文轮廓、厚线和箭尖无裁切；图片可见、表格网格和文字保留，无网络链接。现场视图或主题变化不应改变 SVG 几何，也不写历史。 |
| **X-08 / E-11、E-12** | 本地选 PNG、JPEG，测试撤销、复制和删除；下载后在新会话先加载本地应用，再设为离线并重开。试伪后缀、坏解码、超过字节或像素限额；导入过程中切项目。 | 真实图片离线重开并可继续编辑，同一图片可复用；坏素材不改变项目或历史，旧异步结果不落入新项目。浏览器事件与存档内容都检查；至少一个实际离线重开用例。 |
| **X-09 / E-11、E-12** | 输入含中文的表格，编辑同一格、增删行列、复制后改副本、撤销、重开再编辑；表格编辑中按 `Delete` 与撤销键。 | 单元格数据及行列数正确，副本独立；一次完成的表格编辑记一步，输入时快捷键不会删画布对象。边界数据、非法维度和省略格子拒绝或按需求明示，不造成坏项目。浏览器检查真实输入，另做 Windows 输入法手测。 |
| **X-10 / E-13** | 不启动模型，用纯核心构造「输入 → 处理 → 输出」及独立图元。查询关系，尝试仅改中间节点和获授权箭头；再提交含未知 ID、越权目标或非法锚点的批次。 | 读到真实的有向关系，不把相交计入；正常批次只写授权记录并可一次撤销；出错前的有效命令也不能部分生效，已有重做不变。连接派生变化与真正写入分别断言。 |
| **X-11 / E-14** | 用正式页面从空白走一遍「远处画图 → 目录定位 → 建立关系 → 插入媒体 → 保存 → 离线重开 → 局部修改 → 导出 SVG」。 | 独立于旧小样和 Agent 可操作；有真实浏览器下载与重开、PowerPoint 插入和参赛者操作证据。只完成这批验收，D 正式原创示例和干净副本交付另做。 |

## 批次门与人工复核

| 停点 | 自动化最少覆盖 | 交给参赛者确认 |
| --- | --- | --- |
| 扩展一结束 | X-01～X-03 及原保存、手势回归 | 拖动的是视图；调整窗口后能看更多区域；分类、整组选中、Shift 和定位配合自然。 |
| 扩展二结束 | X-04～X-06、X-07 的无媒体部分 | 开关打开才吸附；矩形、椭圆和星形边缘手感正确；连接跟随、删除与撤销符合预期。 |
| 扩展三结束 | X-01～X-11、A/B/C 完整回归 | 实际重开带图片与表格的项目并改一处；Windows 中文候选取消和快捷键隔离；在目标 PowerPoint 插入并放大 SVG 核对完整性。 |

最终在 Windows 开发环境运行：

```powershell
npm.cmd run test:unit
npm.cmd run typecheck
npm.cmd run build
npm.cmd run test:e2e
```

结果写入同目录 `results.md`（实施时创建），记录对应提交、Node/npm、Chrome/Edge/PowerPoint 版本、命令退出码和通过数、下载项目/导出样例、待复核项。浏览器测试不等价于真实系统文件对话框、Windows 输入法候选窗或 PowerPoint 视觉验收。若目标环境缺失，明确记「未验证」，不写为通过。
