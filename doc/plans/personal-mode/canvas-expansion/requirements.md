# Personal Mode 画布扩展 · 需求与边界

**状态：E-15～E-18 及其对后续批次的影响已获批准，按批实施和验收。** 关联：[实施计划](../2026-11-22-personal-mode-expansion.md) · [验收清单](validation.md) · [原 Personal Mode 需求](../requirements.md)。

## 目标与示例

用户能在更大的工作空间组织图元，并且可以同时从画面和侧栏理解一张图。示例：在不同位置画「输入、处理、输出」，用箭头明确连接，在一旁放入参考图片及数据表。从侧栏即可找到所有矩形、定位远处的「处理」，并查看它连到谁。下一阶段接入 Agent 时，程序不必猜测轮廓是否相交，而可通过稳定 ID 直接读取明确建立的关系。

## 首版需求

| ID | 需求 |
| --- | --- |
| **E-01 兼容** | C3 的 v1 项目以原 ID、绘制顺序、几何、字体和样式打开。新版本项目可携带新增图元、连接和资源；未知版本或错误项目不替换当前内容与历史。旧版软件不要求反向打开 v2。 |
| **E-02 无限画布** | 工作空间不受旧纸面边界限制；用抓手可到视口外创建、编辑和定位对象，并能缩放视图与回到内容。所谓无限是不用先确定纸面尺寸，不是分配一张无限大的图片。 |
| **E-03 窗口可调** | 拖动分隔栏、收起左栏及全屏可改变可视区域；缩放是另外一项操作。不增加输入纸张宽高。视图操作不改变项目坐标、不记录撤销，也不产生未保存提示。 |
| **E-04 分组与选择** | 侧栏按类型分组；展开/收起与整组选中是两个动作。点条目可单选，按住 `Shift` 可加入或移出已有选区；画布和侧栏同步。可从侧栏定位视口外的对象，不要求手工找图。 |
| **E-05 对象检查** | 单选可查看对象类型、位置和适用的颜色、尺寸等参数。关系区只显示已建立的连接，能看到端点对应对象并定位对端；相交、贴边但未建立连接的对象不在列表里。多选视图首版只要求准确显示数量，不承诺批量改样式。 |
| **E-06 新图形** | 「其他图形」提供正方形、菱形、五角星。新图形可选中、移动、缩放和旋转，可改适用的样式、撤销、保存重开和导出。正方形不因正常缩放退化成矩形。 |
| **E-07 可选吸附** | 默认自由绘制。E3–E5 支持直线和箭头端点吸附到闭合图形真实边界；E-18 补充其他线型与目标。靠近时只提示候选，放下或点击确认才绑定；线身经过或视觉相碰不绑定。关闭吸附不抹掉现有关系，仍可自由画线、将线放到图形内。 |
| **E-08 关系随动** | 线和箭头可只绑定一端或绑定两端。目标变换时端点随动，可改接或解除。箭头显示方向，无箭头的线不赋予方向。E3–E5 的目标是矩形、椭圆、正方形、菱形、星形；E-18 扩展目标类型。 |
| **E-09 删除与撤销** | 删除宿主默认保留连线，受影响端在删除前的位置解除绑定，另一端不受影响；撤销一次恢复宿主及关系。改变视图、选区、吸附预览均不产生历史。 |
| **E-10 复制与导出** | 同时复制宿主与连线时，新连接指向对应副本；未复制的宿主不被暗中连接，相关复制端成为自由端。SVG 只输出选中对象及已经解析的几何，不带手柄、视图状态或未选宿主。 |
| **E-11 多媒体** | 本地 PNG/JPG 可插入，并可选中、移动、缩放、旋转、复制；随项目离线重开。表格是可选中、移动、缩放、复制的对象，支持逐格编辑、增删行列和撤销。图片随选区内嵌进 SVG，表格导出为网格线和文字。 |
| **E-12 文件与资源保护** | 非法图片、表格数据或连接引用有明确反馈；不写入历史、不替换当前项目。图片内容只来自本地数据，不依赖原文件名、临时 Object URL 或原始路径；撤销、复制及重开不会丢资源。 |
| **E-13 Agent 前置** | 不接模型即可由程序按稳定 ID 读取图元、真实端点、已绑定对象及方向；通过与界面同一套核心命令，在授权范围内修改或建立关系，合法批次整体撤销，越权或无效批次整体拒绝。 |
| **E-14 交付门** | 走通新场景的制作、保存、离线重开、继续编辑和选区导出，保持现有 C3 输出、Windows 中文输入及浏览器回归。扩展验收后另确认 D，完整交付不在本批宣告。 |
| **E-15 线型分组** | 顶栏「线条」下含直线、折线、曲线；「箭头」下含直线箭头、折线箭头、曲线箭头。原直线手势与旧项目兼容；六种线型共用样式、选区、撤销、项目保存与矢量导出。 |
| **E-16 折线可续画** | 先画一段直线，末端可点击并延伸下一段；切回选择工具后，能选中原折线，从末端继续，保存重开也能续画。续画不新建线对象，折线箭头只在整条线末端有箭头。未确认的预览可取消；撤销一次只撤掉最近确认的一段。 |
| **E-17 手绘曲线平滑** | 自由拖拽画出大致轨迹，系统去掉小抖动、保留主要弯向与首末点，生成可重开编辑的矢量曲线。曲线箭头沿末端切线指向，不自动绕障、不替用户改走向。 |
| **E-18 全元素吸附目标** | 六种线型的首末端都可吸附。所有画布元素均可成为目标：闭合图形用实际轮廓，文字/图片/表格用各自外框，笔迹/线条/箭头用可见路径，允许从一条线的中间引分支。图片和表格在 E6/E7 上线时同步可吸附。仍只有确认的端点才建立关系；笔迹可以被连接，但不自动转成连接线。 |

## 首版行为细节（审核口径）

- **窗口与场景分离：** 视图位置、缩放、展开的分组或选区是会话状态，不进入项目。打开时可用「回到内容」或侧栏定位，不要求恢复关闭前视口。导出裁到选区，不裁到当前窗口。
- **连接与几何接触分离：** 只有明确吸附并提交才有连接。吸附针对端点，不按线身穿越判断，也不自动重接。框选或变换宿主时，派生的连线几何可跟随显示，但不额外改写无关图元。剪贴板中未映射的绑定在粘贴时解除。若变换导致绑定两端暂时落在同一点，保留关系，移开后恢复线形，不凭空生成转弯或自动断开。
- **修改权限：** 受限命令必须获得被修改记录的权限。移动宿主时连线位置的派生变化不等于写入连线记录；删宿主如果会实际改写某个未授权连线，整批拒绝。允许显示给用户的关系与给未来程序读取的关系来自同一模型。
- **续画与改接：** 单击选中折线的末端是续画，拖动是移动或改接端点。末端已经绑定时，预览提示确认后关系随新末端更新；新末端没接到目标就成为自由端。取消预览保留原关系，撤销一次可还原原末段和绑定。普通折点不是可以主动发起绑定的额外端点，但另一条线可吸附其所在路径。
- **跨线连接：** 分支跟随所接主线的同一段位置；追加新段不会挪动已绑定的旧段。删除目标仍在原位置解除受影响端点。禁止线接自己，或两条以上的线互相依赖、导致无法算出位置；普通图形之间用箭头围成环仍允许。文字只按整体外框，图片不追踪透明像素，表格不接单元格，箭头不以箭尖两翼为路径。
- **媒体首版建议限额：** 单图 `10 MiB`、`1600 万像素`；项目图片原始数据合计 `40 MiB`；表格默认 `3×3`、建议最多 `30×20`。这些是审核稿提出的工程边界，不是已实现或已测结果。
- **明确不做：** 不做自动布线、自动布局、完整电子表格、Excel 导入、公式、单元格合并、远程图片、任意 SVG 文件导入、云同步和协作。实际 Agent 对话/模型调用及 PDF/PPTX 导入不在本批。SVG 仍是复用格式，不替代可编辑项目文件。
