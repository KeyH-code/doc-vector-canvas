# Personal Mode 文档画布 · 需求与边界

**状态：** 参赛者已确认 PPT 静态底稿和原页裁切规则，并批准开始开发。关联：[实施计划](../2026-11-23-personal-mode-document-canvas.md) · [验收清单](validation.md) · [验证记录](results.md)。

| 编号 | 需求 |
| --- | --- |
| **DC-01 · 打开与兼容** | 「打开项目」可选择现有项目、PDF 或现代 PowerPoint `.pptx`。打开 PDF/PPTX 创建文档画布项目，不覆盖原文件。旧 v1/v2 仍可读；打开失败、转码取消或未保存确认被取消时，保留现项目及历史。 |
| **DC-02 · 多页画布** | 每个原页面对应一张画布，保留顺序、可见尺寸、比例和方向。PDF 左栏每行一页，缩略图与页码同排，当前页高亮；切页后展开当前页的对象分组，收起上一页。原页画面锁定，不可选、拖动、删除或当作普通图片吸附目标；新增图元继续使用现有工具、属性及撤销规则。右键左栏页面行可隐藏或显示该页底稿，不切页，不改变对象、存档或导出；显隐仅在本次打开期间有效。普通单画布目录不变。 |
| **DC-03 · 页外工作区** | 抓手与缩放照常工作，可在页外放草稿或搬移对象；原页边框醒目。页外内容仍属当前页的编辑层，项目完整保存；同页页内和页外对象可继续使用现有连线关系。页边不是编辑限制。 |
| **DC-04 · 可编辑项目** | 「保存项目」保留稳定页 ID、页内外全部新增图元及连线关系，保存或内嵌重开所需底稿资源。PPTX 保存静态底图即可重开；PDF 保存一份原文档以保留导出所需页面。应用已加载时可离线重开，不要求原文件仍在或 PPTX 转换器仍可用。 |
| **DC-05 · 导出范围** | 「导出文档」提供整份、当前页、指定页码范围。默认遵守原页面尺寸和顺序，跨边部分裁到页框；完全在页外的编辑对象不进入成品。不自动加页、扩页或把被裁掉的箭尖改画在页边。预览提示页外或跨边内容，可继续或返回调整；视口不决定导出内容。 |
| **DC-06 · 导出与存档分工** | 保存项目和导出成品分开。PDF 导出 PDF，PPTX 导出 PPTX；导出不修改原文件、项目、历史、选区或视口。现有「导出选中 SVG」仍只看选中图元、不带底稿，不受原页裁切规则限制，可用来取出页外草稿。 |
| **DC-07 · PDF** | 预览按可见裁切框和页面旋转对齐。导出优先在原页叠加编辑层，保留原文已有的文本层和清晰度，不把原页一律截图；扫描件仍以其原有图像显示，不新增 OCR。导出的 PDF 不承诺还原项目图元或连接。 |
| **DC-08 · PPTX** | 原幻灯片只作为静态底图，不保留原文字、形状、表格、图表、动画或媒体的直接编辑性。导出优先让新增文字、基本形状和线条可在 PowerPoint 单独选中；复杂或跨边图元可在确保外观和裁切正确的前提下输出矢量或透明位图叠加层，必要时提示。不修改原 `.pptx`。 |
| **DC-09 · E8 衔接** | 项目结构能区分文档、页面、锁定底稿、可得的只读原文，以及新增图元与显式关系。后续程序能按页 ID 和图元 ID 读取或受限修改，不能修改原文、底稿或其他页。扫描件/无法提取的 PPTX 页面不伪造文本；页外草稿与页内对象可区分，不自动进入导出。实际 Agent 不在本轮。 |

## 首版范围与未决项

- 仅建议新支持 `.pdf`、`.pptx`；现有项目和单页画布保留。旧 `.ppt` 可另存为 `.pptx`，宏文件、密码保护文件、Word/Excel 专用导入、可编辑原 PPT、PDF 表单/数字签名保留、自动跨页连线、自动扩页、OCR 和真实 Agent 不纳入首版。表格仍可使用 E6 的 PNG/JPG 图元。
- 当前页 PNG 导出、把页外选区生成新幻灯片是后续推荐项，不是本批开发或验收门槛。
- 所选源文档默认本地处理、不上传、不请求文档内外链。PPTX 使用本机 Office、其他本地转换器或纯浏览器渲染仍待 M3 样例验证和授权；先不添加安装或服务依赖。文档容量、页数及静态底图清晰度根据试验再定；现有 E6 图片限额不因此变化。
