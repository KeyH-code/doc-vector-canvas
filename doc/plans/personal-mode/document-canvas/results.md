# Personal Mode 文档画布 · 验证记录

## M0–M2 · 多页与 PDF · 2026-11-23

**状态：** 以 `c06fcd4` 为基线完成第一批（含 PDF 左栏调整），已由参赛者验收并本地提交为 `e3b9d52`。开发依赖锁定为 PDF.js `5.7.284`、pdf-lib `1.17.1`；本批未安装 Office 或其他本地转换组件，也未调用云服务。

| 验收项 | 证据（PDF 部分） |
| --- | --- |
| DV-01 · 入口和保护 | 浏览器用真实 PDF 走「打开项目」；原 v1/v2 仍可打开。损坏 PDF 和取消在途打开均保留旧项目与历史。Edge 生产构建另验证需要密码和仅有所有者密码的两种加密文件均拒绝，不替换现有项目。 |
| DV-02 · 分页和锁定底稿 | PDF 左栏每行一页，缩略图和页码同排；切页高亮并展开对应页的对象，收起旧页，组内选中和定位照常。右键及 `Shift+F10` 都可操作目标页；对非当前页操作不切页。真实 PDF 两页的像素断言验证显隐隔离，保存数据一致、导出仍可读原文，重开恢复底稿。切页和显隐不记历史，跨页撤销定位到编辑页；单画布目录回归通过。 |
| DV-03 · 离线项目 | Chromium 新会话先加载应用，再断网，仅用下载的 v3 项目恢复内嵌 PDF；切到旋转页可见底稿且存档往返一致。Edge 在生产构建中断网重开并下载单页和整份文档，未请求任何第三方地址。 |
| DV-04 / DV-05 · 页外与选页 | 整份、当前页（含旋转页）和指定页码按原顺序输出；非法页码禁止下载。Edge 下载件由独立 PyMuPDF 核对：页内红色线段存在，跨右侧的箭尖未移到页边，页外草稿仍在 v3 项目；旋转、裁切框偏移的第 2 页中叠加对象落在预期坐标。回归检查原稿内部链接不会将未选页内容流复制进成品，打开预览再返回不会提交待确认属性。 |
| DV-06 · 原 PDF 清晰度和文字 | 用真实三页夹具（A 系列比例、裁切偏移与旋转、扫描图）导入导出。独立查看器能从输出重新提取原有中文文本；扫描页保持无文本层。原页内容不栅格化；**新增编辑层**首版以有分辨率上限的透明图片叠加，不保证新增文字在 PDF 内可选取。项目中的新增对象仍可编辑，选区 SVG 仍按原规则工作。 |

**验证：** Windows、Node `22.19.0`；PDF 左栏调整后，`npm.cmd run test:unit` 95 项、`npm.cmd run test:e2e -- --reporter=dot` 71 项、`npm.cmd run typecheck` 和 `npm.cmd run build` 均通过。Edge `158.0.4370.33` 复查亮色桌面和窄窗口暗色布局，确认纵向、旋转、横向页的缩略图均不越出行框。前次生产构建的实际下载用 PyMuPDF `1.27.2.3` 核对了页坐标、像素及原文文本。

**限制：** 首版拒绝加密 PDF，暂定 `32 MiB / 150 页 / 页边长 14,400 pt`；导出逐页嵌入新增层，跳过透明层，新增 PNG 叠加累计最多 `32 MiB`，未测所有极限组合。原页注释、表单动作、签名及附件不列为保真目标。为了应用加载后即可离线处理 PDF，打包时携带本地 worker、字体映射和解码资源；生产构建有 Vite 包大小提示。没有进行新的 Windows 原生输入法人工验收，留待后续总回归。

**测试件：** `.cache/document-canvas-qa/` 包含 `source.pdf`、`review-project.json`、`all-pages.pdf`、`page2-only.pdf` 及 `edge-sidebar-*.png` 等截图，均为本机证据，不进入 Git。建议先打开 `review-project.json`，右键未选中的第 2 页隐藏底稿，再切到第 2 页检查底稿与对象；随后试跨页边箭头导出和项目重开。

**必须在正式 M3 补齐：** 浏览器候选拒绝了截断包和 ZIP 项数超限。外链图片小样揭示库会尝试读取外部 URL；试验页的 CSP 在产生网络请求前拦截，严格导出随即失败。生产接入须在渲染前识别并拒绝外部资源链接，并在隔离的渲染环境禁止联网，不能只依赖库默认行为；另需验证宏、加密、超大压缩包、超时/取消及失败不接管当前项目。样例只含静态元素；SmartArt、嵌入字体、动画/视频和不同系统字体环境未验收。底图持久化、离线重开、正式入口与 PPTX 写出均未实现；不要以该试验替代 DV-07。

## M3 · PPTX 正式导入与离线重开

**状态：** 「打开项目」直接导入及离线项目重开已由参赛者验收。沿用现有多页目录、底稿显隐、按页编辑与撤销；选区 SVG 仍可用。原幻灯片展示为锁定 PNG，不拆分为可编辑对象；隐藏页也作为普通可编辑画布列出，不跳页。每页单存可获得的幻灯片正文及表格文本，未提取备注、图表文本、母版文字或图中 OCR。

- **入口与保护（DV-01）：** PPTX 解析与渲染在无同源权限、禁止外部资源加载的隔离框执行。先验证 ZIP 与文档结构，拒绝外部链接（包括普通外部超链接）、宏容器、重复关系、缺少的内部资源和不支持的编码；渲染、解码和校验完所有页才接管项目。回归包含坏包、宏包、加密容器签名、外链、缺嵌图、重复关系、UTF-16、在途取消和超时。转换会在页面之间让出执行，且两端都拒绝迟到结果；仍不承诺在单次同步解压或栅格化调用中即时打断。
- **逐页保留与重开（DV-02 / DV-03）：** 宽屏和 4:3 三页样例通过浏览器自动化。保存为 v3，PPTX 源只存按原顺序排列的 PNG，不保留原 `.pptx`；后加对象和页外草稿依旧留在各页的编辑层。离线重开恢复各页底稿、尺寸和图元，损坏的项目底稿不覆盖当前画布。
- **上限：** 源文件 32 MiB / 150 页，ZIP 最多 2,000 项、单项展开 32 MiB、合计展开 128 MiB；底稿长边目标 1,600 px，压缩 PNG 合计最多 32 MiB；渲染等待时限 45 秒。小样未验证所有极限组合。布局、字体和图表仅承诺小样口径；不保留动画和交互内容，不承诺嵌入字体/复杂 SmartArt 的同等保真。
- **证据：** 仓库自带 `tests/fixtures/documents/wide.pptx`、`standard.pptx` 及异常样例，复现脚本见 `spikes/pptx-renderer/make_fixtures.py`。类型检查、96 项单测、79 项浏览器测试和生产构建通过（仍有 Vite 包大小提示）。Edge 生产构建在应用加载后断网打开两种比例，实际下载与重开项目并核对底稿像素、尺寸及新增对象，无外部请求或页面错误。两份经桌面 PowerPoint 原生另存的样例和页序重排样例也能断网打开，各三页。生成物在 `.cache/pptx-selection/m3-preview/`。

## M4 · PPTX 导出

**状态：** PPTX 导出已由参赛者验收，与 M3 一并获准本地提交。未进入 E8 或 Agent。使用 PptxGenJS `4.0.1` 本地生成 `.pptx`，不覆盖原演示稿、项目或历史。

- **选择与裁切（DV-04、DV-05）：** 提供整份、当前页和指定页码；选页去重后按原序、尺寸输出。导出始终带静态底稿，无视视图缩放、平移及底稿显隐。完全在页外的对象不写出。跨边箭头、曲线及旋转图片使用原页内的透明图层，按原叠放顺序写入，不补箭尖；报告预计裁切和转图片对象。保存项目仍持有原有图元与页外草稿。
- **可编辑对象（DV-07）：** 底稿设为 PowerPoint 的页背景，不作为可点选形状。页内基本形状、单行文字、单段直线和图片优先写成 PowerPoint 独立对象；箭头、曲线、笔迹、星形、多行或贴边文字以及跨边对象转为局部图片，避免一张大图的选择框挡住远处对象。字体列表转换为单个合法字体名，Office 字距与画布可能略有差异。静态底稿不恢复原图表和表格编辑，原隐藏页作为普通页保留。
- **实际下载件：** Edge 生产构建断网下载 16:9 与 4:3 两种稿的整份、单页；PowerPoint `16.0.14334.21048` 实际打开四份文件，验证页数、原始尺寸和静态页背景，在普通视图逐个选中新增文字、图形和直线，并实际修改文本、移动矩形（不覆盖下载件）。用原生 PowerPoint 导出 PNG 检查红色箭杆到原页边界、不生成新箭尖，完全在页外的测试图形没有写出。下载件与核对图保存在 `.cache/pptx-export-qa/`（`*-final-*.pptx`、`*-native.png`）。
- **资源限制：** PPTX 支持的页边长为 1～56 英寸，超限明确提示，不调整原尺寸。复杂图元 PNG 合计最多 32 MiB、局部渲染累计最多 1 亿像素；新增原生图片累计最多 40 MiB，同页同一素材复用媒体。图片解码导入期间暂不允许创建导出快照。项目长时间处理和原生格式细节仍以实际样例为准。
- **回归：** 99 项单测、82 项浏览器测试、类型检查和生产构建通过。浏览器另核对两个解析器能识别的规范字体字段、图片媒体复用、旋转跨边图不嵌入原图、跨边曲线和组合图层、页码排序与保存件逐字节不变。生产构建仍有包大小提示。
