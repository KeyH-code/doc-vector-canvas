# Personal Mode 文档画布 · 验收清单

**状态：** 验收标准；已执行的 PDF、PPTX 导入和 PPTX 导出部分见[验证记录](results.md)。关联：[需求](requirements.md) · [实施计划](../2026-11-23-personal-mode-document-canvas.md)。

| 验收项 | 操作 | 通过标准 |
| --- | --- | --- |
| **DV-01 · 入口和保护（DC-01）** | 从正式文件入口打开原 v1/v2、真实 PDF 和真实 PPTX；试未保存确认取消、不支持格式、坏文件、加密 PDF 或转换中切项目。 | 旧项目正常；不支持或失败时有可理解的反馈，现有对象、项目和撤销/重做均保留，不展示半个文档。成功打开才切换项目。 |
| **DV-02 · 分页与底稿（DC-02～DC-04）** | 在第 1、2 页分别绘制和连接，检查 PDF 左栏单列、页内对象分组、展开/折叠；右键当前行和非当前行（另试 `Shift+F10`），显隐后翻页、保存、导出及重开；撤销后重做。 | 缩略图与页码同排，当前页高亮，切页时只展开目标页；单画布目录不变。右键显隐只改该页屏幕上的底稿，不选页、不改对象或历史；保存数据不变，导出照常包含底稿，重开恢复显示。跨页撤销能看见受影响页；ID、顺序和原尺寸稳定。 |
| **DV-03 · 离线项目（DC-04）** | 实际下载 PDF/PPTX 项目，在新浏览器会话先打开应用再断网，只用项目文件重开。在一页继续编辑并保存。 | 无需原路径、原 PPTX 或 PPTX 转换器；所有底稿、页内外编辑和关系恢复，可继续编辑。静态站点首次加载能力不等于离线重开。 |
| **DV-04 · 页外裁切（DC-03、DC-05、DC-06）** | 同一页放页内字、完全页外草稿、跨边厚线/曲线/旋转图片，把箭头尖放到页外。分别以 `50%`、`200%` 并用抓手移到页外后导出。再用选区 SVG 取页外草稿。 | 预览能提示受影响页和对象，取消预览不改状态；文档只带页内部分，不插新页或改尺寸，页边不补箭尖；项目仍保留完整对象，SVG 选区仍可单独带走页外草稿。 |
| **DV-05 · 范围与对齐（DC-02、DC-05、DC-07、DC-08）** | 下载整份、当前页、非连续页码范围，核对原顺序；输入零、越界及错误范围。PDF 另试混合尺寸、偏移裁切框和旋转页；PPTX 分别试 16:9 与 4:3。 | 文件页数、顺序及尺寸符合范围；单页只含该页，页边角标与新增图元对齐。错误范围不生成残缺文件。 |
| **DV-06 · PDF 文字和清晰度（DC-07）** | 以含中文文本页和扫描页的真实 PDF 导入、加线及文本后导出，在独立查看器搜索并复制原中文，放大检查。 | 原有文字层可查可复制，页内新增图元清晰；扫描页不产生伪文本。记录原 PDF 特性限制，而非声明全部保真。 |
| **DV-07 · PPTX 保真与可选对象（DC-08）** | 用实际 `.pptx` 样例含中文、母版、普通表格、图表、内嵌位图。用目标 Windows PowerPoint 打开导出件，试选中新增文字和基本形状，检查跨边区域及复杂图元降级。 | 底稿为静态页，字体/版式差异和本地组件前提有记录；支持的新增对象可单独选中，不能原生转换的对象外观正确且降级能识别。禁止通过依赖未获批准的转换方式假称已通过。 |
| **DV-08 · 按页结构化关系（DC-09，随 E8）** | 在两页使用相同的测试对象 ID，按页读显式关系；尝试编辑授权页、越权页及底稿。再测页外草稿和扫描页。 | 按「页 ID + 图元 ID」定位，不误串页；底稿、越权对象不可写，拒绝整批并保持历史；报告只读文本的可用性和页外范围，不从截图猜关系。 |

### 批次与证据

- **M0–M2：** 先交多页 PDF 测试项目、整份和单页下载件，请参赛者实际验证 DV-01～DV-06 的 PDF 部分。
- **M3：** 用 16:9 与 4:3 的真实文稿从「打开项目」导入，核对包括隐藏页在内的页序、原尺寸和静态底稿；在不同页画图，保存项目并断网重开。损坏、宏、加密、外链或取消转换不替换现项目。此停点不要求 PPTX 写出。
- **M4：** 交整份和单页 PPTX、可编辑项目和 Windows PowerPoint 检查记录，补齐 DV-04、DV-05 和 DV-07 的 PPTX 导出部分。
- **E8：** 合并 DV-08 和[原画布回归](../canvas-expansion/validation.md)，保留真实 Windows 中文输入法和 PowerPoint 核对。D 仍单独确认。
- 证据记录在本目录 [results.md](results.md)，含基线、命令、依赖版本、导出文件、失败或未测项。全量命令：`npm.cmd run test:unit`、`npm.cmd run typecheck`、`npm.cmd run build`、`npm.cmd run test:e2e`。
